# Bitácora de análisis

[Curso](../README.md) · [Proyecto](../proyecto/README.md)

Completa una entrada por decisión. Distingue predicción de resultado observado.

| Campo | Qué registrar |
|---|---|
| Pregunta | Qué quieres describir o contrastar |
| Unidad | Qué representa una fila y qué clave la identifica |
| Entrada | Archivo, origen, diccionario y huella cuando corresponda |
| Predicción | Resultado esperado antes de ejecutar |
| Acción | Código, comando y raíz de trabajo |
| Observación | Resultado, filas, denominador y faltantes |
| Decisión | Qué cambió y por qué |
| Límite | Qué no demuestra esa evidencia |

Ejemplo de expectativa: una unión de encuesta con modalidad única por grupo debe conservar 36 IDs y no crear modalidades faltantes. Si el catálogo repite A, el flujo debe rechazar la cardinalidad prevista antes de resumir.

Conserva el archivo original. Si modificas una copia, anota política de conversión, filas afectadas e incidencias. Un resultado limpio sin ese registro no explica qué información se excluyó.
