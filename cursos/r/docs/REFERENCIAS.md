# Referencias para profundizar

[Curso](../README.md)

Las fuentes oficiales permiten contrastar funciones y supuestos. Revisa la ayuda instalada de tu versión; una página de desarrollo puede describir cambios posteriores.

- [Proyecto R](https://www.r-project.org/) y [manuales](https://cran.r-project.org/manuals.html).
- [RStudio Desktop](https://posit.co/download/rstudio-desktop/).
- [dplyr](https://dplyr.tidyverse.org/) y [contratos de uniones](https://dplyr.tidyverse.org/reference/mutate-joins.html).
- [tidyr](https://tidyr.tidyverse.org/).
- [ggplot2](https://ggplot2.tidyverse.org/).
- [readr](https://readr.tidyverse.org/) y [readxl](https://readxl.tidyverse.org/).
- [Quarto con R](https://quarto.org/docs/computations/r.html).
- [Ayuda de t.test](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/t.test.html) y [lm](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/lm.html).
- [Ayuda de cor](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cor.html) y [cor.test](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cor.test.html).
- [NIST: intervalo para una media](https://itl.nist.gov/div898/handbook/eda/section3/eda352.htm).
- [ASA: principios de interpretación de p-valores](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf).
- [renv](https://rstudio.github.io/renv/): ampliación para estudiar bloqueo y restauración de dependencias; no está activado en este proyecto.

El software produce cálculos bajo un contrato. Elegir una prueba exige además pregunta, diseño, unidad de independencia, supuestos y contexto; la disponibilidad de una función no justifica su uso.
