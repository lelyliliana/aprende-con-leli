# R desde cero para análisis de datos e investigación

**[Comenzar por la Unidad 00](unidad00-ruta/README.md)** · [Ver el curso](https://lelyliliana.github.io/aprende-con-leli/cursos/r/)

Curso abierto de nivel principiante a intermedio para pasar de una pregunta y un archivo de datos a un análisis explicado y reproducible. Incluye **19 unidades, 55 ejemplos comprobables, 18 soluciones ejecutables completas y un proyecto construido en cuatro etapas con informe Quarto**.

No exige conocer Python ni haber programado. Necesitas manejar archivos y operaciones aritméticas básicas; la ruta introduce programación y los conceptos estadísticos utilizados. Se trabaja con datos ficticios suministrados en el curso.

Cada unidad desarrolla una clase escrita, un laboratorio guiado cuando corresponde, experimentos, errores frecuentes, una práctica en tres pasos, un reto y respuestas de autoevaluación. Las soluciones explican todos los pasos y los retos; los archivos ejecutables acompañan esa explicación.

## Qué aprenderás a entregar

Una tabla leída con su diccionario, decisiones de calidad trazables, transformaciones con denominadores claros, figuras con unidades e interpretación y un informe reconstruible. La ruta introduce inferencia y regresión con supuestos explícitos; el proyecto final es descriptivo.

## Cómo estudiar

1. Lee la pregunta y predice el resultado con datos pequeños.
2. Ejecuta un ejemplo completo desde la raíz del proyecto.
3. Compara salida, cantidad de registros y significado de las variables.
4. Resuelve la práctica antes de consultar la solución.
5. Conserva una decisión justificada y un caso que pueda detectar un error.

## Herramientas y comprobaciones

R 4.3 o superior y los paquetes declarados. RStudio es una opción de editor; los ejemplos también se ejecutan con Rscript. Quarto se instala para renderizar el informe de la Unidad 17. No necesitas Python ni una cuenta de pago. La guía contempla Windows, macOS y Linux.

Desde cursos/r, después de preparar paquetes:

```text
Rscript --vanilla scripts/verificar.R
```

Para incluir el informe, con Quarto instalado:

```text
Rscript --vanilla scripts/verificar.R --quarto
```
