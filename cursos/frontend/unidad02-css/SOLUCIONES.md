# Soluciones desarrolladas de la Unidad 02

[Unidad](README.md) · [Construcción paso a paso](DESARROLLO.md)

Intenta primero los ejercicios. Compara el razonamiento y las condiciones, además del resultado visible.

## Ejercicio 1. Separación

El gap de `.acciones` separa campo y botón. Cambiar .6rem por 1rem aumenta esa distancia. El margen de `.tarjeta` regula otra separación, entre la tarjeta y elementos exteriores. Señala el selector y nivel afectados.

## Ejercicio 2. Ventana estrecha

A 500 px o menos la media query coloca acciones en columna. Comprueba 320, 375 y un ancho amplio. El criterio es ausencia de desbordamiento y controles utilizables, no que cada pantalla tenga una copia distinta del diseño.

## Ejercicio 3. Teclado

En paso 3, Tab debe identificar campo, botón y filtro; después las acciones de las tareas existentes. Conserva focus-visible. Si un control está disabled no lo uses como evidencia de que el teclado falla.

## Reto desarrollado

Mantén el contenedor fluido, la reorganización de acciones y el texto divisible. Cambia colores y comprueba contraste de sus estados reales. Una palabra larga debe partirse sin ocultar el botón Eliminar. No resuelvas un desbordamiento recortando toda la página.
