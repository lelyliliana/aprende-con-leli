## Objetivos

Preparar la práctica y distinguir estructura, estilo e interacción.

## Explicación y práctica guiada

El proyecto es un plan de estudio con tareas: agregar, marcar como completa, eliminar y filtrar. Conservaremos el mismo modelo al pasar de JavaScript a React. La etapa inicial muestra estructura y datos ficticios; las etapas interactivas guardan en el navegador.

No se exige haber cursado una asignatura universitaria. Si partes desde cero, consulta los temas públicos enlazados en cada unidad, realiza sus ejercicios y vuelve al proyecto. Si ya puedes resolver la comprobación, puedes pasar al siguiente punto.

Para practicar necesitas Node.js 24 LTS desde 24.15.0, npm, un editor y un navegador. Git es opcional para descargar y actualizar; también puedes usar el ZIP del repositorio. Sigue el [arranque del laboratorio](../laboratorio/README.md). No se requiere Java, una base de datos externa, Docker ni servicios de pago.

Comprueba con node --version y npm --version. Conserva abierta la terminal de npm run dev; detenerla deja de servir la aplicación. Las instrucciones se escriben para una terminal en Windows, macOS o Linux, pero la verificación registrada se ejecutó en Linux.

Las tres páginas se sirven en el mismo puerto. index.html representa la primera etapa, javascript.html la segunda y react.html la tercera. Las dos últimas usan la misma clave de almacenamiento: puedes cerrar una versión, abrir la otra y seguir con los mismos datos. No abras ambas para editar simultáneamente: esta práctica no sincroniza cambios entre pestañas.

## Ejercicios

1. Inicia el laboratorio y abre la etapa de HTML y CSS. Identifica qué controles están deshabilitados y por qué.
2. Anota qué necesitas repasar: estructura HTML, estilos CSS, funciones JavaScript o estado React. Consulta solo el tema necesario.
3. Describe qué esperas que sobreviva a una recarga del navegador y qué cambiaría si usas otro puerto.

## Reto

Explica el recorrido de una tarea desde el formulario hasta su presentación posterior. Señala qué papel cumple cada tecnología.

## Errores frecuentes

Intentar abrir JSX con doble clic; confundir el repositorio con una aplicación ya ejecutándose; asumir que datos locales se sincronizan entre equipos.

## Comprobación para avanzar

Puedes iniciar y detener el laboratorio, abrir sus tres páginas y elegir qué conocimientos necesitas repasar.
