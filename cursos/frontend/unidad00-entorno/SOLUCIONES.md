# Soluciones de la Unidad 00

[Volver a la unidad](README.md)

Intenta los ejercicios primero.

La etapa HTML presenta controles deshabilitados porque todavía no ejecuta el comportamiento. JavaScript gestiona eventos y DOM; React representa el estado mediante componentes. Los datos locales pertenecen al navegador y origen: cambiar protocolo, host o puerto cambia el almacenamiento que puedes leer.

Para el reto, comprueba que tu propuesta satisface las condiciones de la unidad y explica una decisión. Puede haber varias implementaciones válidas; no basta cambiar la apariencia sin comprobar comportamiento.
