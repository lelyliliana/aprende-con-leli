## 1. Criterio de respuesta

Una evidencia útil indica el dato recibido, la transformación y el resultado esperado. Un programa que compila todavía puede incumplir su regla.

## 2. Criterio de respuesta

El modelo debe impedir estados inválidos, como una cantidad negativa. El menú no debe ser el único lugar donde se compruebe una regla indispensable.

## 3. Criterio de respuesta

Una nueva JVM pierde colecciones de memoria. El archivo permite reconstruirlas si formato, ruta y lectura son válidos; guardar no prueba por sí solo recuperación.
