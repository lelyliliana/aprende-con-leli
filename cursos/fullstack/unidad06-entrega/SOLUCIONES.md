# Soluciones de la Unidad 06

[Volver a la unidad](README.md)

Intenta los ejercicios antes de leer. Las respuestas explican criterios y admiten otras implementaciones coherentes.

1. La URL de API puede llegar al navegador. La contraseña de PostgreSQL pertenece al entorno del backend. El tamaño de página puede ser configuración del cliente dentro de límites del servidor; el puerto es configuración del proceso que escucha.

2. dist contiene archivos de interfaz. El JAR se ejecuta en otro proceso. Preview puede reenviar /api para la comprobación local, pero ese proxy no acompaña a dist cuando lo copias a cualquier alojamiento.

3. Una guía reproducible indica carpeta de ejecución, versión, comandos, puerto y resultado esperado. Corrige expresiones como “ejecuta desde aquí” cuando no indican ubicación.

**Reto:** justifica un servidor que entrega interfaz y reenvía /api, un proceso Java y una base con almacenamiento persistente. Explica configuración externa y recuperación de copias sin declarar probado un despliegue que no realizaste.
