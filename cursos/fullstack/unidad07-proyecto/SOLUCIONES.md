# Soluciones de la Unidad 07

[Volver a la unidad](README.md)

Intenta los ejercicios antes de leer. Las respuestas explican criterios y admiten otras implementaciones coherentes.

1. Para un catálogo de materiales: crear código único (rechazo de duplicado); consultar por nombre (consulta vacía válida); actualizar nombre/precio (rechazo de versión antigua). Cada criterio indica acción, respuesta y cambio observable.

2. Una decisión defendible puede ser separar cliente HTTP del componente para probar y reutilizar peticiones, o elegir H2 en archivo para práctica local. Describe también límites frente a un entorno multiusuario.

3. La entrega debe poder iniciarse sin rutas exclusivas de tu equipo. Una prueba en copia nueva detecta dependencias olvidadas, archivos no versionados y órdenes que requieren estar en otra carpeta.

**Reto:** muestra un flujo y un fallo real con recuperación, después explica una decisión. No es una solución única: se evalúa correspondencia entre problema, implementación y evidencia, con los criterios de la unidad.
