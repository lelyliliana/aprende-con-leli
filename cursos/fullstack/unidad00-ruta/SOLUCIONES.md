# Soluciones de la Unidad 00

[Volver a la unidad](README.md)

Intenta los ejercicios antes de leer. Las respuestas explican criterios y admiten otras implementaciones coherentes.

1. El navegador captura la entrada y muestra el resultado; el servidor recibe, valida y coordina el guardado. La base conserva los registros. Cerrar la pestaña no borra una base; detener H2 en memoria sí elimina esa ejecución.

2. Omitir un repaso exige evidencia: un formulario accesible, una petición interpretada o un componente modificado. Haber visto un tema no demuestra poder usarlo.

3. Una bitácora útil registra un experimento: “predije 404 al apagar Java; observé conexión rechazada; aprendí que 404 requiere respuesta del servidor”. No necesita credenciales.

**Reto:** el texto del formulario pasa a JSON, el Controller lo valida, el Service aplica reglas y el Repository guarda. Una lectura posterior devuelve datos que React representa. Distingue cerrar cliente de detener servidor.
