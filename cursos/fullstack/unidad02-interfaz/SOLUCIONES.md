# Soluciones de la Unidad 02

[Volver a la unidad](README.md)

Intenta los ejercicios antes de leer. Las respuestas explican criterios y admiten otras implementaciones coherentes.

1. Una ayuda posible para SKU: “Usa un código único con mayúsculas, números y guion”. Explica el formato requerido sin pedir conocer el nombre del DTO.

2. Cambiar texto visible no requiere cambiar name o campos JSON. htmlFor debe coincidir con el ID de su control. Comprueba teclado y foco además de leer el código.

3. Carga conserva la espera; vacío describe una consulta correcta; entrada inválida muestra motivo y conserva el formulario; creación confirmada muestra éxito y puede limpiar. Un fallo de respuesta obliga a comprobar antes de repetir la escritura.

**Reto:** la maqueta debe mantener etiquetas, orden de teclado y mensajes legibles en ventana estrecha. No dependas solo del color ni ubiques acciones fuera del área visible.
