# C++ desde cero: fundamentos, objetos y recursos

**[Comenzar por la Unidad 00](unidad00-ruta/README.md)** · [Ver el curso](https://lelyliliana.github.io/aprende-con-leli/cursos/cpp/)

Ruta de principiante a intermedio con **22 unidades, 42 ejemplos completos, 21 soluciones ejecutables y un proyecto construido en cuatro etapas**. No exige conocer C, Python ni otro lenguaje. Introduce los conceptos de programación antes de utilizarlos en diseños mayores.

La base de compilación es C++20. Aprenderás a explicar un programa, conservar identidad y unidades, gestionar recursos y generar un reporte a partir de datos ficticios. Las clases están escritas para autoestudio e incluyen lectura de código, experimentos, errores frecuentes, práctica progresiva, retos y respuestas razonadas.

## Cómo estudiar

1. Lee la pregunta y predice una salida pequeña.
2. Construye un ejemplo completo y sigue sus estados.
3. Cambia una decisión en una copia de práctica y explica su efecto.
4. Completa los tres pasos y el reto antes de consultar la solución.
5. Conserva una evidencia y un caso que deba rechazarse.

## Proyecto final

[Construcción por etapas](proyecto/CONSTRUCCION.md) · [Guía de entrega](proyecto/README.md) · [Reporte de ejemplo](proyecto/muestra/reporte.csv)

El inventario identifica materiales ficticios, exige campos y dominios, calcula en centavos enteros y conserva un reporte ordenado. Separa lectura, cálculo y escritura. La versión de consola recibe entrada y salida y rechaza una salida existente o una entrada inválida antes de producir resultados.

El formato delimitado tiene un contrato restringido. El proyecto es local, de un proceso; no implementa transacciones de archivos, recuperación ante cortes ni concurrencia. Interfaces gráficas, videojuegos, microcontroladores y concurrencia requieren otras rutas. El curso introduce plantillas y conceptos, sin presentarse como una formación avanzada completa de todo C++.

## Comprobar la entrega

Después de preparar el entorno, desde cursos/cpp:

```text
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
```

Una vez configurado:

```text
cmake --build build --config Debug --parallel 2
```

Cuando termine la construcción:

```text
ctest --test-dir build -C Debug --output-on-failure
```
