# Soluciones de la Unidad 00

[Volver a la unidad](README.md)

Intenta los ejercicios antes de consultar.

1. Saludo corresponde a fundamentos; CRUD sin base a REST en memoria; versión/concurrencia a JPA. La API integrada añade otros controles, por lo que no debe usarse para aprender primero un POST sin identidad.

2. mvn -version indica el JDK efectivo y Maven. Los comandos con -f se ejecutan desde la raíz del curso público, donde no hay un pom.xml general.

3. Una bitácora útil registra una diferencia concreta entre expectativa y observación. “Funciona” no describe qué se comprobó.

El reto debe distinguir generar un artefacto, iniciar un proceso, obtener HTTP y cumplir una regla: ninguna de esas evidencias sustituye automáticamente a las otras.
