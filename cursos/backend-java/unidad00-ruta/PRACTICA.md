# Práctica aplicada de la Unidad 00

[Unidad](README.md) · [Desarrollo](DESARROLLO.md) · [Práctica](PRACTICA.md) · [Soluciones](SOLUCIONES.md)

Completa un paso antes de seguir con el siguiente. Consulta las soluciones después de intentarlo.

## Paso 1. Elegir sin instalar otra tecnología

Clasifica estas tareas: cambiar un prefijo, crear un recurso sin base, rechazar una versión vieja y probar un permiso. Escribe para cada una el proyecto y su pom. No ejecutes todavía la integrada.

## Paso 2. Registrar el entorno

Ejecuta primero `java -version` y después `mvn -version`. Guarda versiones y raíz de trabajo en una bitácora propia. Si Maven utiliza otro JDK, resuelve ese punto con la guía de entorno antes de continuar.

## Paso 3. Preparar dos copias identificables

Sigue los dos primeros pasos del [laboratorio](../laboratorio/README.md). Identifica dónde está esta ruta y dónde quedó Curso-Spring-Boot. Registra la revisión fijada con `git rev-parse HEAD` desde la segunda copia.

## Paso 4. Definir una evidencia de cierre

Completa una fila con predicción, comando, resultado esperado y dato posterior. Usa la consulta de un catálogo vacío como primer ejemplo. Explica qué faltaría para demostrar duración entre reinicios.

Entrega las cuatro asignaciones, versiones y una fila de bitácora. Continúa a la primera API cuando puedas localizar el pom sin adivinar la carpeta.
