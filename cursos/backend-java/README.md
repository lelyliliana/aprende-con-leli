# Backend y APIs con Java

[Ver el curso en Aprende con Leli](https://lelyliliana.github.io/aprende-con-leli/cursos/backend-java/)

Ruta aplicada de nivel intermedio para construir, conectar, probar y operar una API. Reutiliza cuatro proyectos del curso público de Spring Boot y enlaza conceptos cuando hacen falta. No depende de cursos universitarios ni duplica su código.

Debes poder trabajar con clases, colecciones, excepciones y pruebas sencillas de Java. La Unidad 00 te ayuda a decidir qué repasar antes de avanzar.

## Cómo estudiar

Predice una respuesta, ejecuta el laboratorio, observa, modifica y explica. Cada unidad incluye ejercicios, reto, soluciones y comprobación de cierre. Usa el tema del curso público cuando lo necesites y vuelve a esta ruta para aplicar la decisión.
