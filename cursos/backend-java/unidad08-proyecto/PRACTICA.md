# Práctica aplicada de la Unidad 08

[Unidad](README.md) · [Desarrollo](DESARROLLO.md) · [Práctica](PRACTICA.md) · [Soluciones](SOLUCIONES.md)

Completa un paso antes de seguir con el siguiente. Consulta las soluciones después de intentarlo.

## Paso 1. Delimitar un usuario y tres requisitos

Completa la plantilla con una persona usuaria y un recurso. Para cada requisito incluye caso válido, límite y rechazo. Si utilizas precio máximo 500, decláralo como ampliación propia que todavía debes implementar.

## Paso 2. Resolver un tramo completo

Entrega creación, consulta y rechazo por duplicado antes de continuar a otra función. Conserva ejemplos de entrada/salida y una consulta posterior que demuestre estado correcto.

## Paso 3. Añadir duración y edición segura

Declara motor y modo de almacenamiento. Demuestra reinicio y un intento de actualización con versión antigua. Explica cuál parte comprobaste realmente.

## Paso 4. Reproducir desde otra copia

Sigue tu README desde una carpeta nueva, sin reutilizar variables ocultas de una terminal previa. Corrige la primera instrucción ambigua. Registra revisión, herramientas y comandos con sus raíces.

## Paso 5. Preparar una demostración de cinco minutos

Muestra un flujo válido, entrada rechazada, versión antigua conservando datos y diagnóstico mediante respuesta/log. Si solo pruebas dos versiones sucesivas, no lo presentes como una carrera de peticiones simultáneas.

## Paso 6. Autoevaluar

Asigna puntos con evidencia por los seis criterios del desarrollo. Anota dos decisiones justificadas y una limitación verificable. Entrega README, fuentes, pruebas y configuración de ejemplo sin secretos.
