# Soluciones de la Unidad 07

[Volver a la unidad](README.md)

Intenta los ejercicios antes de consultar.

1. Health presenta un resumen limitado; metrics revela información operativa que la política protege. La exposición debe corresponder a una necesidad y permiso.

2. El request ID correlaciona registros locales asociados a la petición; no representa por sí solo identidad o recorrido entre varios servicios.

3. Una hipótesis medible define carga/tasa, duración, percentil, errores y máquina/datos. La prueba debe registrar resultados antes de afirmar mejoras.

El reto compara una dependencia adicional, pero no permite atribuir toda diferencia a red sin otras señales. No se realizó una prueba de carga completa en la verificación de esta ruta.
