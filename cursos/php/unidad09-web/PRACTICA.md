# Práctica 09. HTML, HTTP y páginas dinámicas

[Volver a la lección](README.md) · [Consultar después: soluciones](SOLUCIONES.md)

## Antes de escribir

Explica con tus palabras: Explicar el viaje de una petición y generar HTML con salida escapada.

## Hazlo en tres pasos

1. Identifica título, párrafo y enlace en una página HTML.
2. Predice qué ocurre con el texto <b>PHP</b> al escaparlo.
3. Reto: genera un párrafo con el nombre Ana & Luis escapado.

## Entrega y autocontrol

- Un archivo propio que resuelva el reto, sin copiar primero la solución.
- Una predicción y la salida real de los tres ejemplos; explica cualquier diferencia.
- Un caso normal y uno límite o inválido con resultado esperado.
- Un párrafo sobre el error que encontraste y cómo lo investigaste.

Compara después con SOLUCIONES.md. Si tu respuesta difiere, comprueba el contrato antes de cambiarla: puede haber varias soluciones correctas.

## Taller de profundización

1. **HTTP:** ejecuta el laboratorio 09-http y registra método, URL completa, estado y tipo de contenido de una petición.
2. **Contexto:** muestra el título PHP & HTML en HTML y en JSON; explica por qué las representaciones tienen diferencias.
3. **Experimento:** envía un nombre con <b> y demuestra que se ve como texto; inspecciona también el cuerpo de la respuesta.
4. **Diseño:** crea una página con título, párrafo y lista de tres talleres, manteniendo las etiquetas fijas y los títulos escapados.

Conserva tu primera versión y una corregida. Justifica cada cambio con una entrada concreta; no reemplaces una explicación por «ahora funciona».
