# Práctica 00. Tu primer programa y cómo estudiar

[Volver a la lección](README.md) · [Consultar después: soluciones](SOLUCIONES.md)

## Antes de escribir

Explica con tus palabras: Distinguir editor, intérprete, terminal y navegador; ejecutar y modificar un programa.

## Hazlo en tres pasos

1. Ejecuta los tres ejemplos y copia la salida.
2. Cambia el saludo por tu nombre.
3. Reto: muestra tres pasos para preparar una clase, cada uno en una línea.

## Entrega y autocontrol

- Un archivo propio que resuelva el reto, sin copiar primero la solución.
- Una predicción y la salida real de los tres ejemplos; explica cualquier diferencia.
- Un caso normal y uno límite o inválido con resultado esperado.
- Un párrafo sobre el error que encontraste y cómo lo investigaste.

Compara después con SOLUCIONES.md. Si tu respuesta difiere, comprueba el contrato antes de cambiarla: puede haber varias soluciones correctas.

## Taller de profundización

1. **Comprender:** dibuja el recorrido archivo → intérprete → terminal. Explica dónde se guarda el texto y dónde se ve el resultado.
2. **Construir:** escribe cuatro instrucciones para organizar una clase. Imprime cada una en una línea y agrega un comentario que no deba aparecer.
3. **Investigar:** ejecuta desde una carpeta diferente usando una ruta correcta y otra incorrecta. Guarda los mensajes sin modificar el programa.
4. **Transferir:** explica qué herramienta añadirías para convertir la salida en una página web y qué parte seguiría ejecutándose en PHP.

Conserva tu primera versión y una corregida. Justifica cada cambio con una entrada concreta; no reemplaces una explicación por «ahora funciona».
