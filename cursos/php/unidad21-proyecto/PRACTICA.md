# Práctica 21. Proyecto integrador: gestor de talleres

[Volver a la lección](README.md) · [Consultar después: soluciones](SOLUCIONES.md)

## Antes de escribir

Explica con tus palabras: Entregar una aplicación local explicada, comprobada y ampliable.

## Hazlo en tres pasos

1. Completa las cuatro etapas de CONSTRUCCION.md.
2. Evalúa la entrega con RUBRICA.md y vincula cada criterio con una evidencia.
3. Reto: diseña una ampliación de categorías indicando esquema, validación y tres casos de prueba.

## Entrega y autocontrol

- Un archivo propio que resuelva el reto, sin copiar primero la solución.
- Una predicción y la salida real de los tres ejemplos; explica cualquier diferencia.
- Un caso normal y uno límite o inválido con resultado esperado.
- Un párrafo sobre el error que encontraste y cómo lo investigaste.

Compara después con SOLUCIONES.md. Si tu respuesta difiere, comprueba el contrato antes de cambiarla: puede haber varias soluciones correctas.

## Taller de profundización

1. **Historias:** escribe tres usos con entrada, permiso, resultado y evidencia. Vincúlalos con las etapas de construcción.
2. **Integración:** ejecuta el tercer ejemplo y localiza en qué archivo real vive cada función; demuestra que no cambia tu base de estudio.
3. **Defensa:** prepara la explicación de cinco minutos y demuestra un rechazo que conserve los datos anteriores.
4. **Ampliación:** diseña una fecha de taller o una categoría con cambios de esquema, contrato API y tres casos de prueba; implementa solo después de revisar ese mapa.

Conserva tu primera versión y una corregida. Justifica cada cambio con una entrada concreta; no reemplaces una explicación por «ahora funciona».
