# Aprende con Leli

**Cursos abiertos de programación, desarrollo web, análisis de datos, inteligencia artificial e IoT.**

Aprende a tu ritmo con explicaciones, ejemplos, prácticas, retos y proyectos. Los contenidos están organizados por conocimientos y objetivos, con requisitos y puntos de entrada para distintos niveles de experiencia.

[**Explorar los cursos**](https://lelyliliana.github.io/aprende-con-leli/) · [**Elegir una ruta**](#rutas-de-aprendizaje) · [**Conocer a Leli**](https://lelyliliana.com/)

## Comienza por aquí

- **Si empiezas desde cero:** sigue la ruta [Empieza a programar](https://lelyliliana.github.io/aprende-con-leli/rutas/empieza-programar/).
- **Si tienes un objetivo concreto:** elige un curso del catálogo y revisa sus conocimientos previos.
- **Si quieres construir un proyecto web o conectar dispositivos:** sigue una de las rutas que encontrarás más abajo.
- **Si buscas analizar datos con R:** puedes empezar [sin conocimientos previos de programación](https://lelyliliana.github.io/aprende-con-leli/cursos/r/).

## Cómo aprovechar los materiales

1. Lee los objetivos y prepara el entorno indicado en el curso.
2. Estudia la explicación, predice el resultado y ejecuta los ejemplos.
3. Resuelve las prácticas y los retos antes de consultar las soluciones disponibles.
4. Construye el proyecto por etapas y explica tus decisiones.
5. Utiliza las comprobaciones del curso para revisar tu trabajo y conserva los archivos necesarios para reproducirlo.

Las instrucciones de instalación y ejecución están en cada curso. Los requisitos varían según el lenguaje, las herramientas y, en los cursos de electrónica, los dispositivos utilizados.

## Qué contiene este repositorio

Aquí se mantiene el sitio de **Aprende con Leli**, su catálogo, las rutas y parte de los materiales educativos.

- [cursos/](cursos/): páginas de los cursos y materiales alojados en este repositorio, incluidos R, C++, Frontend, Backend con Java y Full Stack.
- [rutas/](rutas/): recorridos que relacionan varios cursos.
- [src/data/courses.json](src/data/courses.json): catálogo de cursos, niveles, requisitos y repositorios fuente.
- [src/data/paths.json](src/data/paths.json): composición de las rutas.
- [src/data/areas.json](src/data/areas.json): áreas de aprendizaje.
- [src/](src/): navegación, búsqueda, estilos y tema claro u oscuro.
- [docs/](docs/): documentación del proyecto.

Algunos cursos conservan su contenido en repositorios independientes. Desde la página de cada curso puedes acceder a su guía y código fuente; el catálogo identifica el repositorio correspondiente.

## Calidad y mantenimiento

Los contenidos se revisan y amplían de forma continua. Las comprobaciones dependen de cada curso: ejecución de ejemplos, prácticas, enlaces, proyectos y presentación de resultados.

En este repositorio, los cursos de [PHP](.github/workflows/verificar-php.yml), [R](.github/workflows/verificar-r.yml) y [C++](.github/workflows/verificar-cpp.yml) cuentan con verificaciones automatizadas en GitHub Actions. Consulta [las ejecuciones](https://github.com/lelyliliana/aprende-con-leli/actions) para conocer su estado.

Si encuentras un error, puedes [abrir una incidencia](https://github.com/lelyliliana/aprende-con-leli/issues). Indica el curso, la unidad, el archivo o enlace y, si corresponde, el mensaje de error y el resultado esperado.
