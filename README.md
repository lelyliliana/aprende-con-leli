# Aprende con Leli

Plataforma educativa abierta de **lelyliliana** para organizar cursos, rutas de aprendizaje, ejemplos, retos y proyectos relacionados con tecnología.

## Propósito

**Aprende con Leli** busca ofrecer una experiencia de aprendizaje organizada por conocimientos y objetivos, independientemente de la estructura académica o administrativa de las asignaturas donde algunos materiales hayan sido utilizados originalmente.

La plataforma funciona como una capa de navegación pedagógica sobre recursos educativos mantenidos en repositorios independientes.

## Principios

- Aprender mediante ejemplos y proyectos.
- Organizar los contenidos por rutas de aprendizaje y no por asignaturas.
- Permitir distintos puntos de entrada según los conocimientos previos.
- Reutilizar recursos existentes sin duplicarlos innecesariamente.
- Mantener los repositorios fuente independientes.
- Facilitar la incorporación futura de nuevos cursos y áreas tecnológicas.

## Áreas previstas

La arquitectura permitirá incorporar progresivamente contenidos de:

- Programación.
- Desarrollo web.
- Backend y APIs.
- Python y análisis de datos.
- Git, GitHub y herramientas para desarrolladores.
- Algoritmos.
- Bases de datos.
- Inteligencia artificial.
- Arduino, ESP32 e IoT.
- Robótica.
- Otras áreas tecnológicas.

Solo se mostrarán públicamente como cursos o rutas disponibles los contenidos que estén preparados para su publicación.

## Estructura conceptual

Una persona podrá:

1. comenzar desde cero;
2. elegir un área específica;
3. seguir un curso completo;
4. recorrer una ruta que combine recursos de distintos cursos;
5. consultar ejemplos y retos;
6. acceder al código fuente correspondiente en GitHub.

## Repositorios fuente iniciales

Entre los recursos que podrán alimentar las primeras rutas se encuentran:

- Curso Desarrollo de Software I.
- Curso Lenguaje de Programación I.
- Curso Lenguaje de Programación II.
- Curso Lenguaje de Programación III.
- Curso Desarrollo de Software II.
- Curso de Python.
- Guía Git, GitHub y Visual Studio Code.

Estos repositorios no serán modificados por la plataforma para reorganizar sus contenidos. **Aprende con Leli** mantendrá las referencias y relaciones necesarias para construir las rutas públicas.

## Ecosistema lelyliliana

La plataforma está concebida como el área educativa del ecosistema profesional de **lelyliliana** y podrá integrarse posteriormente con **lelyliliana.com**.
